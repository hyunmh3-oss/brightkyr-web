<p><span style="color: rgb(5, 5, 5); font-family: &quot;Segoe UI Historic&quot;, &quot;Segoe UI&quot;, Helvetica, Arial, sans-serif; font-size: 15px; letter-spacing: normal; white-space: pre-wrap;">Второй год проекта Жаркын Кыргызстан начался в полном масшабе. 27-го января профессора сестринского дела Корейской Республики с сотрудниками проекта вместе посетили Кыргызскую Республику.  В первые два приезда началось семинаром по совместной исследовательской работе КГМА,  семинар с преподавательским  составом  по укреплении научно-исследовательскай способности и  семинар по развитию  практического курса  сестринское дело в региональной обществе. Также открытие второго года проекта, церемония открытия центра по укреплению здровья детей, собрание с консультативным советом, собрание с исполнительным комитетом, совместная встреча с исполнительным комитетом и активистами, встреча с активистами, расширенние предоставления услуг по укреплению здоровья детей, проведение обучения по проведению Health Scout( Здравоохранительный товарищ), консультация по совместному сотрудничеству между UNICEF-Bright Kyrgyzstan и т.п. различными встречами гладко смогли вступить во второй год проекта.</span><br></p><p><img src="/images/uploaded/summernote/202302/f0940537cde7026a79fbf43d5f87146e.jpg" style="width: 50%;"><img src="/images/uploaded/summernote/202302/8621853da0f9ea40ea215584af6a1463.jpg" style="width: 50%;"><span style="color: rgb(5, 5, 5); font-family: &quot;Segoe UI Historic&quot;, &quot;Segoe UI&quot;, Helvetica, Arial, sans-serif; font-size: 15px; letter-spacing: normal; white-space: pre-wrap;"><br></span></p>
