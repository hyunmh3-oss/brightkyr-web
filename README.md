# Bright Kyrgyzstan 홈페이지

경희대학교 NURSphere Lab의 BK-LUPIC 사업 홈페이지를 직접 관리할 수 있는 형태로 다시 만든 것입니다.
원본(`brightkyr.khu.ac.kr`, 외주 제작)의 화면을 그대로 옮겼습니다.

- 한국어 · 영어 · 키르기즈어 · 러시아어 4개 언어
- 전체 809쪽 (고정 페이지 24 + 게시물 769 + 메인·목록·자료실 16)
- 운영비 0원 (Cloudflare 무료 범위)

## 2. 폴더 구조

```
brightkyr-new/
├─ content/              ← 글·페이지 내용 (여기만 고치면 화면이 바뀐다)
│  ├─ news/{ko,en,ky,ru}/<번호>.md
│  ├─ social/{ko,en,ky,ru}/<번호>.md
│  └─ pages/{ko,en,ky,ru}/*.md
├─ public/               ← 이미지·글꼴·CSS·첨부파일 (그대로 배포됨)
│  ├─ css/               ← 한국어 CSS
│  ├─ en/css/, ky/css/, ru/css/   ← 언어별 CSS (내용이 서로 다르다)
│  ├─ images/            ← 사진 1,677장
│  ├─ files/             ← 게시물 첨부파일
│  ├─ fonts/             ← 자체 보관 글꼴
│  └─ sub/pop_privacy.html 등  ← 푸터 팝업
├─ src/
│  ├─ layouts/Base.astro       ← 머리말·메뉴·꼬리말
│  ├─ components/              ← 메인, 목록, 글보기
│  ├─ i18n/                    ← 메뉴·꼬리말·메인 문구 (언어별)
│  └─ pages/[...path].astro    ← 모든 주소를 만드는 곳
├─ _수집자료/            ← 원본에서 받아온 자료 (배포 안 됨, 보관용)
└─ 보류작업.md           ← 남은 일 목록
```

## 3. 글 쓰기 · 고치기

### 3-1. 있는 글 고치기

`content/news/ko/59.md` 같은 파일을 열면 이렇게 생겼습니다.

```markdown
---
title: "글 제목"
lang: "ko"
kind: "news"
board: "news"
idx: "59"
no: "48"
category: "공지사항"
author: "관리자"
date: "2025-03-04"
hits: "120"
attachments:
  - name: "파일이름.pdf"
    file: "/files/news/파일이름.pdf"
youtube: ""
---

<p>본문 HTML</p>
```

`---` 사이가 글 정보, 아래가 본문입니다.

| 항목 | 뜻 |
|---|---|
| `title` | 글 제목 |
| `lang` | 언어 (`ko` `en` `ky` `ru`) |
| `idx` | 주소에 쓰이는 번호. **바꾸면 주소가 바뀐다** |
| `no` | 목록 번호 칸에 나오는 값. **비워 두면 '공지' 딱지가 붙고 맨 위로 간다** |
| `category` | 목록의 분류. 분류 선택 상자와 같은 말을 써야 걸린다 |
| `date` | 등록일 |
| `attachments` | 첨부파일. `public/files/...` 에 실제 파일이 있어야 링크가 걸린다 |
| `youtube` | 유튜브 주소를 넣으면 본문 맨 위에 영상이 뜬다 |

### 3-2. 새 글 쓰기

같은 폴더에 `<번호>.md` 파일을 새로 만들고 위 형식대로 씁니다.

- 파일 이름의 번호와 `idx` 값을 같게 맞춥니다.
- 번호는 그 폴더에서 가장 큰 번호 + 1을 쓰면 됩니다.
- 언어마다 폴더가 따로이므로, 4개 언어에 올리려면 파일도 4개 만듭니다.

**메인 화면의 '사회적 영향'·'뉴스' 칸은 최신 글이 자동으로 올라갑니다.**
(본문에 사진이 하나 이상 있어야 메인에 뜹니다. 사회적 영향 10건, 뉴스 5건)

### 3-3. 고정 페이지 고치기

`content/pages/ko/about.md` 등을 고칩니다.

```markdown
---
title: "소개"
lang: "ko"
pageKey: "about"
visual: "Home > 브라이트 키르기즈스탄 > 소개"
---
```

- `pageKey` 는 주소를 정합니다. **바꾸지 마세요.**
- `visual` 은 제목 아래 경로 표시(`Home > … > …`)입니다.

### 3-4. 메뉴·꼬리말 고치기

- 메뉴: `src/i18n/nav.ts`
- 꼬리말(주소·연락처·SNS): `src/i18n/footer.ts`
- 메인 화면 문구·협력기관 목록: `src/i18n/home.ts`

### 3-5. 사진 넣기

`public/images/` 아래에 넣고 본문에서 `<img src="/images/...">` 로 부릅니다.

**용량 주의**: 한 파일이 25 MB를 넘으면 Cloudflare가 받지 않습니다.
사진은 보통 1 MB 이하입니다. 동영상은 유튜브에 올리고 `youtube` 항목에 주소를 넣으세요.

## 4. 화면 확인하기

바꾼 내용을 올리기 전에 내 컴퓨터에서 보는 방법입니다.

```bash
npm install
npm run dev
```

터미널에 나오는 주소(`http://localhost:4321`)를 브라우저에서 엽니다.
파일을 고치면 화면이 바로 바뀝니다. 멈추려면 터미널에서 `Ctrl+C`.

배포와 같은 결과물을 보려면:

```bash
npm run build
npm run preview
```

GitHub에 올리면 Cloudflare가 알아서 다시 짓고 반영합니다.

## 6. 알아두면 좋은 것

### 언어마다 CSS가 다르다

원본이 `/css/`, `/en/css/`, `/ky/css/`, `/ru/css/` 를 따로 두고 있습니다.
키릴 문자가 길어서 메뉴 여백 등이 언어마다 조정돼 있습니다
(메뉴 항목 좌우 여백: 한국어·영어 60px, 러시아어 36px, 키르기즈어 27px).
**한 언어의 CSS를 고쳐도 다른 언어에는 반영되지 않습니다.**

### 바깥 서비스에 기대지 않는다

글꼴(NanumSquare, Pretendard, Noto Sans, Roboto, S-CoreDream)과
자바스크립트 라이브러리를 전부 이 저장소 안에 넣었습니다.
원본은 rawgit·jsdelivr·Google Fonts를 불러왔는데, 그 서비스가 멈추면 화면이 깨집니다.

### 목록 검색과 쪽 넘김

원본은 서버가 10건씩 잘라 보냈지만, 이 사이트에는 서버가 없습니다.
목록 전체를 한 번에 내려보내고 브라우저에서 걸러 보여줍니다.
**화면과 조작은 원본과 같지만, 쪽을 넘겨도 주소가 바뀌지 않습니다.**

### 첨부파일이 없으면

`attachments` 에 적혀 있어도 `public/files/` 에 실제 파일이 없으면
링크 대신 회색 글씨로 이름만 보여줍니다. 눌러도 오류가 나지 않습니다.

## 8. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 배포했는데 안 바뀜 | Cloudflare 대시보드에서 빌드가 실패했는지 확인 |
| 빌드 실패 | 대개 `.md` 파일의 `---` 사이 형식 오류. 따옴표 짝이 맞는지 보기 |
| 사진이 안 보임 | 경로가 `/images/` 로 시작하는지, 파일이 실제로 있는지 |
| 첨부가 회색으로만 보임 | `public/files/` 에 그 이름의 파일이 없음 |
| 글이 목록에 안 나옴 | `lang` 값이 폴더와 맞는지, `idx` 가 파일 이름과 같은지 |
